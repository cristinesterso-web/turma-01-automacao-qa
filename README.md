# turma-01-automacao-qa

# Atividade - Casos de Teste

## O que foi feito

Criei um tipo `CasoDeTeste` com as propriedades:
- id
- titulo
- descricao
- automatizado

Também criei uma função para criar casos de teste e uma função para verificar se um caso é automatizado.

## Como rodar

Você abre o projeto no VS Code, abre o terminal dele, verifica se o Node.js tá instalado no computador. Depois executa o arquivo `casos-de-teste.ts`, em seguida os resultados dos testes vão ser exibidos no terminal.

## Erro de tipo

 Provoquei um erro passando uma string no parâmetro `id`, que deveria receber um número.
